# AI-generated psychological safety measures

This project has two parts, each with its own README and requirements.

- [`six-condition-prototype/`](six-condition-prototype/): the first prototype. Six prompt conditions with one captured scale each, and a synthetic demonstration of factor analyses and coefficient comparisons.
- [`multiscale-design/`](multiscale-design/): the Stage 2 analysis. Respondents answer several AI-generated scales, and a random-effects model estimates how much the psychological safety–team learning correlation varies across measures. It currently runs on simulated scales and will use the team's logged generation pool.
