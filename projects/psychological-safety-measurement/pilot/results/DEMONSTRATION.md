# Executed synthetic demonstration — illustrative only

The executable prototype was run on one deterministic synthetic dataset with N = 600 and 700 paired bootstrap replications. **No respondent data were collected and no properties of the six AI-generated item sets were estimated.**

## Composite-score regressions

Efficacy-adjusted standardized coefficient using synthetic reference scale: **0.2317**.

| Hypothetical alternative | Adjusted coefficient | Difference from reference | Paired 95% bootstrap interval |
|---|---:|---:|---|
| Equivalent measurement | 0.2646 | +0.0328 | [−0.0147, 0.0838] |
| Lower precision | 0.2006 | −0.0311 | [−0.0990, 0.0337] |
| Efficacy overlap | 0.2827 | +0.0510 | [−0.0016, 0.1000] |
| Learning-behavior overlap | 0.5612 | +0.3295 | [0.2774, 0.3845] |
| Sparse learning overlap (two items) | 0.3528 | +0.1211 | [0.0772, 0.1717] |

These differences depend on stipulated factor loadings. Sampling variation explains why independently simulated but equivalent scales do not yield exactly identical coefficients.

## EFA and CFA

EFA was performed by principal-axis extraction with oblimin rotation on one 300-person split; machine-readable loading tables are generated by the script.

The following CFA results are approximate continuous-normal maximum-likelihood fits to the **other** 300-person split (7-point ordinal responses treated as numeric).

| Item block | CFA model | χ² (approx.) | df | RMSEA (approx.) |
|---|---|---:|---:|---:|
| Reference safety + efficacy + learning | Three separate factors | 110.635 | 116 | 0.0000 |
| Reference safety + efficacy + learning | Safety merged with learning | 501.908 | 118 | 0.1043 |
| Sparse-overlap safety + efficacy + learning | Simple three-factor model | 221.449 | 116 | 0.0551 |
| Sparse-overlap safety + efficacy + learning | Three factors + two specified cross-loadings | 91.538 | 114 | 0.0000 |

All four model optimizations converged. A correctly specified model improved fit for the deliberately introduced cross-loading mechanism. This result cannot validate the actual generated item wording.

## Reproduce

```bash
python -m pip install -r requirements.txt
python simulation/synthetic_demo.py --out results
```

The run regenerates item responses and full CSV/JSON model summaries with a fixed seed. A repeated Monte Carlo simulation, ordinal WLSMV CFA, and empirical psychometric validation remain future tasks.
